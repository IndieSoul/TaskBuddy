# TaskBuddy

TaskBuddy is a simple and efficient task management app designed to help you organize your day. With an intuitive interface and customization options, TaskBuddy keeps you on top of your to-dos and helps you achieve your goals.

## Features

- 📝 **Create tasks**: Add new tasks with personalized details like title, notes, due dates, and category colors.

## System Requirements

- **Platform**: iOS 18.0 or higher
- **Tools required**:
  - Xcode 16 or higher
  - Swift 6 or higher
